About the Author

IT 3203: Intro to Web Development

Terra Hall

Hello. I am a student in IT 3203 Introduction to Web Development at Kennesaw State University. I created this website as part of an assignment to research and explain a core component of web technology.

I chose Browser Developer Tools for my project because they are an essential, but often overlooked part of using the modern web. They offer a free and easily accessible way for anybody to explore the internet, and they are conveniently built inside your browser. It is a great way to learn hands-on. You get to experience the results in real time.

Project Purpose

This website turns my research presentation into an easy and structured website. It provides details on the history of DevTools, how to open them, the core panels used for debugging, and the key concepts every web developer should know.
