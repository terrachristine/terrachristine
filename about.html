About the Author

IT 3203: Intro to Web Development

Terra Hall

Hello! I am a student in IT 3203: Introduction to Web Development. I created this website as part of an assignment to research and explain a core component of web technology.

I chose Browser Developer Tools because they are an essential, yet often overlooked, part of the modern web experience. Whether you are an aspiring developer, a designer, or just someone curious about how websites are built, DevTools offer a free and accessible way to peek under the hood of the internet.

Project Purpose

This website translates my research presentation into an accessible, structured resource. It covers the history of DevTools, how to open them, the core panels used for debugging, and the key concepts every web developer should know.

All HTML and CSS on this site was written by hand, without the use of frameworks or templates, as a requirement for this course.
