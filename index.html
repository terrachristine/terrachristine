An Introduction to Browser Developer Tools

IT 3203: Intro to Web Development | Research by Terra Hall

Abstract

Browser Developer Tools (DevTools) are built-in features found inside all modern web browsers. They allow anyone to inspect, test, edit, and debug website code and network activity live in real-time. This research website explains the basic parts of DevTools, the main screens used to find and fix visual or coding mistakes, and why testing website speed and performanace matters so much today.

Key Terms

  • DOM (Document Object Model): The tree structure representing a webpage's HTML.
  • Client-Server Model: The architecture where the browser (client) requests data from a server.
  • Breakpoint: A marker that tells the browser to pause JavaScript execution so you can inspect it.
  • CDP (Chrome DevTools Protocol): The communication language between DevTools and the browser engine.
