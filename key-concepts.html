Key Concepts of Developer Tools

Essential terminology for mastering the browser's sandbox

Concept Definition
DOM (Document Object Model) The tree structure representing a webpage's HTML. The Elements panel visualizes this tree, allowing you to manipulate page structure.
Client-Server Model The architecture of the web where your browser (the client) sends a request to a server, which replies with data like HTML or images.
CDP (Chrome DevTools Protocol) A remote debugging protocol that lets tools like DevTools, Puppeteer, and Playwright control and monitor Chromium-based browsers.
Breakpoint A deliberate marker set on a line of code in the Sources panel that pauses JavaScript execution so you can inspect variables and logic.
Device Mode A feature that simulates mobile screen sizes, touch events, and slow network connections to test responsive web designs.
Waterfall Timeline A visual graph in the Network panel that shows the start time, duration, and dependency chain of every downloaded file.
Lighthouse An automated auditing tool built into DevTools that scores a website on performance, accessibility, best practices, and SEO.
