Hands-On Workflows: The Panels

Part 2 & 3: Visuals, Layout, and Logic

The Elements Panel: Inspecting & Editing HTML

The Elements panel is where you inspect the structure of a page. All changes made here are temporary and local; refreshing the page will completely reset the site. You can double-click text strings to edit them, double-click attributes to change image sources or links, and drag elements up or down to reorder the DOM tree.

The Styles Pane

Located next to or below the HTML Elements panel, the Styles pane is a live playground for CSS. You can change colors, spacing, and typography instantly to see how edits look before modifying your permanent codebase. Pro-tip: Use the :hov button to force an element into a hover or active state so you can edit its interactive effects.

The Console Panel: Troubleshooting JavaScript

The Console acts as your diagnostic dashboard. It displays errors (red), warnings (yellow), and standard logs generated by developers using commands like console.log(). You can also use the Console as an interactive scratchpad. Simply type JavaScript directly next to the blinky indicator (>) to test logic snippets instantly and manipulate the page behavior on the fly.

The Sources Panel: Precision Debugging

Moving beyond console.log(), the Sources panel allows you to pause JavaScript in real-time. By clicking directly on any line number in your script files, you set a breakpoint. This freezes the browser's execution timeline, allowing you to use step-by-step traversal buttons to track exactly how variable values change line-by-line.

The Network Panel: Monitoring Web Traffic

The Network panel tracks every individual asset the browser downloads to display the page, including images, fonts, scripts, and API payloads. Use the Waterfall Timeline to visually analyze the loading order and duration of files to see exactly which image or script is causing a page delay. It also provides color-coded HTTP status checks (like a green 200 OK or a red 404 Not Found).
